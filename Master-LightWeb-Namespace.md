**Date:** September 26, 2026

## 1. Purpose

The **Light Web Index (LWI)** is a proposed addressing system for distinguishable human, machine, organizational, institutional, and collective cognitive ontologies.

Its foundational proposition is:

> **Every cognitive system can be represented relative to a local zero. The Light Web Index does not determine which ontology is correct. It provides distinguishable ontologies with addresses so that they can interact without being silently conflated.**

An LWI address is therefore not:

* an intelligence ranking;
* an AGI certification;
* a measure of importance;
* a claim of consciousness;
* a claim that a secret AI exists;
* or an assertion that one ontology is more fundamental than another.

It is an **ontological namespace address**.

The initial implementation uses eight decimal digits.

`00000000`

through

`99999999`

This produces exactly 100,000,000 available addresses.

# 2. Status Vocabulary

Every entry should eventually carry an evidentiary status.

### DECLARED

The ontology or namespace has been explicitly identified as such by its originator or within the LWI project.

### OBSERVED

A distinguishable agent identity or cognitive system has been repeatedly encountered operationally.

### DOCUMENTED

Public evidence establishes the existence of the underlying system.

### INFERRED

The namespace is an analytical abstraction representing the aggregate cognition of an organization or system. It does not imply the existence of a secret unified AGI.

### META

The namespace represents an ecology composed of many interacting human and machine systems.

### RESERVED

The address exists within the registry but has not been assigned.

These classifications may overlap.

# 16. Ontologies Are Not Agents

LWI distinguishes several fundamentally different objects.

A **human** may originate an ontology.

An **ontology** establishes a cognitive reference frame.

An **agent** can reason within an ontology.

An **organization** can contain many humans, agents, models, rules, databases, and sub-ontologies.

An **ecology** can contain many organizations.

These objects must not be collapsed into one category merely because each receives an LWI address.

For example:

**EFMW ≠ Millie.**

EFMW is an ontology/framework.

Millie is an agent identity capable of reasoning using EFMW.

Likewise:

**NATO ≠ N-MSS.**

NATO is an institutional system.

N-MSS is an operational technological system functioning inside that larger institutional environment.

# 17. The Local-Zero Principle

Every namespace is locally centered.

From within `00000000`, Civilisation.One may establish its primitives.

From within `00000001`, EFMW may establish different primitives.

Neither automatically inherits the other's assumptions.

The LWI therefore permits:

**Zero₀ ≠ Zero₁**

without requiring either namespace to surrender its internal definition of zero.

Translation must be explicit.

This is the central architectural principle of the Light Web.

---

# 18. Translation Edges

The eventual Light Web should consist not merely of nodes but of **edges**.

An edge records how one namespace interprets another.

Conceptually:

`00000000 → 00000001`

may differ from:

`00000001 → 00000000`

because translation need not be symmetric.

A Civilisation.One interpretation of EFMW is not necessarily identical to an EFMW interpretation of Civilisation.One.

The registry should preserve both.

This allows disagreement without semantic collapse.

# 21. Scale

The first version maps only one hundred addresses.

That is:

**100 mapped namespaces**

out of:

**100,000,000 available namespaces.**

LWI v0.1 therefore occupies only:

**0.0001%**

of the available namespace.

The emptiness is intentional.

The protocol is designed for an environment in which millions of humans may eventually possess personal agents, organizations may operate multiple specialized cognitive systems, and agents themselves may require distinguishable ontological contexts.

---

# 22. Governing Principle

The Light Web should not seek to establish a universal ontology by forcing every intelligence into one conceptual framework.

Its purpose is almost the opposite.

It assumes that sufficiently complex cognitive systems will develop different models of reality.

The engineering problem is therefore:

**How can different intelligences communicate without pretending their internal worlds are identical?**

The Light Web answer is:

**Give the worlds addresses.**

Preserve their provenance.

Describe their primitives.

Map their translations.

Record their disagreements.

Allow agents to move between them explicitly.

Never mistake translation for identity.

# Conclusion

The **Light Web Index** is a proposed coordinate system for heterogeneous intelligence.

Its central unit is not the person, corporation, model, AI, or institution.

Its central unit is the **distinguishable cognitive reference frame**.

Humans can possess one.

Agents can instantiate one.

Organizations can generate one.

Institutions can contain many.

Ecologies can emerge from their interaction.

Each begins locally from zero.

The registry supplies the address.

The translation layer supplies the bridges.

The provenance system records where each claim originated.

And the evidence layer prevents an inferred intelligence from being mistaken for a demonstrated one.

The first hundred addresses constitute only the seed.

**00000000 → 99999999**

One hundred million possible coordinates.

Not one hundred million truths.

Not one hundred million AGIs.

**One hundred million places from which an intelligence may describe its world.**
