How this differs from the script

  • Every agent runs its own 484-weight network. The script allocates a genome per agent but evaluates one shared network, so all agents behave alike.
  • Distances wrap around the world edges, matching how agents move. Dead agents stay dead; in the script a dead slot can revive if it harvests energy.
  • Mutation rate is the chance that each weight is perturbed at birth, and mutation scale is the size of the perturbation. The script defines the rate but perturbs every weight.
  • Coherence is the absolute value of the memory term. With the update rule in the script, memory settles at half of the first network output, so coherence stays at or below 0.5.
  • Everything else follows the script: 8 inputs, two hidden layers of 16 tanh units, 4 outputs, one birth per step, and a population cap of 95% of the slots.
